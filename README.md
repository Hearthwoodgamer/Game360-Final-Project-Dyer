## Game Overview
 Genre: Action Platformer
 Platform: Windows  
 Development Time: 8 weeks  
 Unity/Unreal Version: unity 6 
 Course: GAME 360 - Development with Game Engines, Fall 2025

 

## How to Play
Download the build, run the exe file. Controls are A/D left/right, space = jump, arrows keys to shoot in those directions, esc is pause. 

## Features
Implemented most of the features listed on the GDD

Implemented Mechanics
- Wallclimbing
- Walljumping
- Score System
- Collectibles
- Win/Lose Conditions

## Architecture
Implemented previous patterns used (Observer, state machine, ect)
